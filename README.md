# Repartos

Página "envoltorio" de la app de reparto de uvas: da el nombre **Repartos** y el ícono 🍇
al agregarla a la pantalla de inicio del celular, y muestra adentro la app (Google Apps Script).

- La clave de acceso NO está aquí: viene en el link que manda el coordinador (`…/repartos/#k=CLAVE`).
- Ícono: emoji de uvas de [Twemoji](https://github.com/jdecked/twemoji) (licencia CC-BY 4.0).
